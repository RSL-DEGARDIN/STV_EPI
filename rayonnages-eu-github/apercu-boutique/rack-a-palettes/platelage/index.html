Description

Apprenez à reconnaître quel platelage vous est le plus adapté. Ci-dessous vous trouverez une description de nos différents platelages pour rayonnages de stockage disponibles. A savoir que les types de produits que vous cherchez à stocker ainsi que leur poids influent sur le choix final du plancher.

  • Le platelage sapin : Planches d’épaisseur 23, 27 ou encore 30 mm reliées par des tasseaux qui facilitent l’insertion entre les lisses. Ce type de platelage est idéal pour le stockage de petits colis pour un coût relativement bas. Il s’adapte très bien aux différentes dimensions du rayonnage de stockage que vous possèderez.
