Description

La butée palette, aussi appelée stop palette, est un dispositif conçu pour faciliter la dépose des palettes sur les rayonnages et assurer leur alignement. Elle est particulièrement utile pour éviter la poussée excessive des palettes dans les palettiers double face et pour protéger les murs ou bardages dans les palettiers simple face.

Details : butée composée de : 2 consoles en tôle plié profondeur 100mm + 1 tube galva de 40×40 mm ep:2mm, visserie incluse.
