Description

Le séparateur tube est un accessoire utilisé dans les rayonnages industriels pour organiser et sécuriser le stockage de produits longs ou encombrants. Il permet de diviser l’espace de stockage et d’éviter le mélange des articles.

Caractéristiques

  • Matériau : Acier galvanisé ou peint.
  • Dimensions : Longueur 1050 mm, section 40 x 20 mm.
  • Installation : Se fixe sur les lisses du rayonnage avec un système de blocage.
  • Finition : Disponible en coloris orange RAL 2004.
  • Utilisation : Idéal pour le stockage vertical de tubes, profilés ou planches
